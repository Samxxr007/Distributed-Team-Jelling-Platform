# Jelling Environment

Distributed-team collaboration platform with real-time AI sentiment analysis.

## Features
- Real-time chat
- Team health dashboards
- Sentiment analysis

## Quick Start
```bash
git clone ...
cd jelling-environment
cp backend/.env.example backend/.env
docker compose up --build
```
Open http://localhost:3000
Demo: admin@jelling.com / password123

## Tech Stack
- Frontend: React
- Backend: Python FastAPI
- DB: PostgreSQL, Redis
- Ops: Docker, Kubernetes
